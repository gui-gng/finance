# Budgets

Already implemented: per-category monthly budgets with progress bars, month selector.

## Features

- [ ] **Threshold alerts** — warn at 80% and 100% of a category budget; surface an alert badge on the dashboard.
- [ ] **Budget vs actual trend** — 6/12-month line chart of budgeted vs spent per category.
- [ ] **Budget templates** — copy all budgets from a previous month to a new month in one click.
- [ ] **Rollover budgets** — option to carry unused budget (or overspend debt) into the next month per category.
- [ ] **Savings goals** — target amount + deadline per goal, with progress and "on track / behind" status.
- [ ] **Budget pace indicator** — given the day of month, show whether spending is ahead of or behind linear pace per budget.
- [ ] **End-of-month forecast** — project final spend per category based on current run-rate and recurring commitments.
- [ ] **Total budget summary** — one card: sum of all budgets vs sum spent, with overall %.
- [ ] **Subcategories** — two-level categories (e.g., Alimentação > Restaurantes) with budgets at either level.
- [ ] **Flexible budget periods** — weekly or custom date-range budgets in addition to monthly.
- [ ] **Budget allocation planner** — enter monthly income and allocate with the 50/30/20 rule as a starting suggestion.
- [ ] **Income tracking** — register income transactions so net/budget math is complete, not expense-only.
- [ ] **Annual budget view** — year grid (categories × months) with conditional coloring for over/under.
- [ ] **Over-budget digest** — list of all categories over budget this month with the overspend amount.
