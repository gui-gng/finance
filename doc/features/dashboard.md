# Dashboard Customization & Usability

Goal: let the user shape the dashboard to what they care about, and make common tasks fewer clicks.

## Features

- [x] **Widget visibility toggles** — each dashboard section (stats, budgets, monthly flow, category/holder doughnuts, invoice totals, weekday, top establishments, recurring) can be shown/hidden via a "Customize" panel; choice persisted in `localStorage`.
- [x] **Widget reordering** — sections can be moved up/down in the "Customize" panel; order persisted in `localStorage`.
- [x] **Budget month selector** — budget progress widget shows a month picker (`<input type="month">`) so the user can inspect budget status for any month, not just the current one.
