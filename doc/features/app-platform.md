# App & Platform

Quality-of-life and platform-level improvements.

## Features

- [ ] **Light theme toggle** — alternate light color scheme; persist choice.
- [ ] **Mobile navigation** — collapsible sidebar / hamburger layout for small screens.
- [ ] **PWA support** — installable app with service-worker caching for faster loads.
- [ ] **Authentication** — login per user so personal data isn't open on the local network.
- [ ] **API token / env-based API base** — replace the hardcoded `http://localhost:8080/api` with a config setting (dev/prod).
- [ ] **Keyboard shortcuts** — e.g., `g d` dashboard, `g t` transactions, `/` to focus search.
- [ ] **i18n** — pt-BR / en translation layer for the whole UI.
- [ ] **Empty states & onboarding** — friendly first-run screens when no data is imported yet.
- [ ] **Undo toasts** — toast notifications with undo for destructive actions (delete category, toggle paid).
- [ ] **Settings page** — currency/locale, theme, reminder preferences, default filter period.
