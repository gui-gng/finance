# Feature Documentation

Product/feature specs for the finance app. Features are marked `[x]` when implemented and verified; `[ ]` means pending.

| File | Scope |
|------|-------|
| [dashboard.md](features/dashboard.md) | Dashboard customization & usability |
| [invoices.md](features/invoices.md) | Credit card invoice & card control |
| [budgets.md](features/budgets.md) | Budgets & savings goals |
| [transactions.md](features/transactions.md) | Transaction management |
| [insights.md](features/insights.md) | Insights, alerts & proactive nudges |
| [data-import.md](features/data-import.md) | Parsers, import workflow & data tools |
| [app-platform.md](features/app-platform.md) | App shell, platform & quality of life |

Ideas drawn from 2026 fintech/expense-tracker research (multi-card dashboards, subscription tracking, predictive budgets, anomaly detection) and adapted to this app's CSV-fatura data model.
